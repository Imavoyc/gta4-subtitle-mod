# 节目风格（喂给翻译模型的背景说明）

这是 GTA IV（自由城）里的电视节目，风格是**美式商业电视的讽刺腔**：粗俗、浮夸、
充满广告推销腔和新闻腔的自我吹嘘。翻译时：

- **Weazel News**：地方台新闻，主播一本正经地念荒诞内容；越正经越好笑。
- **CNT**：同样荒诞的新闻/纪录片，语气更"精英"一点。
- **广告**：夸张的推销腔（"你值得拥有"），口号要短、有力。
- **扑克秀 / 真人秀**：体育解说的亢奋语气。
- 脏话、性暗示、暴力玩笑**照原意保留**，不要净化、不要自我审查。
- 人名/机构/品牌按术语表；术语表没有的专名先音译，并在校对时补进术语表。
